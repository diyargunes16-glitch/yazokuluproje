# Yaz Okulu Odevi - Stok Takip Programi

Basit bir Java konsol uygulamasi olarak stok takibi yapmak icin baslangic projesi.

## Ozellikler

- Urun ekleme
- Urun listeleme
- Stok girisi / cikisi
- Urun arama

## Calistirma

```bash
mvn compile
mvn exec:java -Dexec.mainClass="com.yazokulu.stoktakip.Main"
```

> Not: Ilk asamada proje iskeleti hazir. Sonraki adimlarda menu ve veri kaydi genisletilebilir.
